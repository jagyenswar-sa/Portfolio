Prompt engineers and students lack a fast, setup-free workspace to test temperature, Top-P, few-shot templates, and live streaming reasoning models side by side without switching tools.

LLM Token Explorer (Tokeniser v2.5)

Problem Statement

Developers learning LLMs often treat tokenization, subword BPE merges, and vector embeddings as black boxes, making token costs and character-splitting errors hard to intuit.

Solution Architecture

Client-side modular JS suite combining multi-model subword segmentation, an interactive BPE vocabulary merge simulator, a 2D HTML5 Canvas 3D-projection embedding explorer with depth-sorted hit testing, and a logits sampling simulator.

Tech Stack

HTML5, CSS3, Vanilla JavaScript, Tailwind CSS (CDN), HTML5 Canvas 3D projection.
