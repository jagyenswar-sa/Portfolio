AI & Prompt Engineering

LLM Playground (Groq LPU Inference)

Single-file HTML/CSS/JS app • Tailwind CSS, Marked.js & Highlight.js via CDN

A fast, single-file prompt engineering workspace built around Groq LPU inference with real-time streaming, reasoning traces, and latency benchmarking.

  • Controls for Temperature (0.00–2.00), Top-P, and Max Tokens alongside dynamic Zero/One/Few-shot prompt indicators and templates.
  • Streams DeepSeek R1 reasoning blocks, cited web search results, live throughput (tok/s) and TTFT (ms), plus Python, cURL, and JS code export.

What I learned: Buffering partial Server-Sent Events chunks from ReadableStream while separating <think> reasoning tokens from live Markdown output taught me how streaming UIs handle backpressure and cancellation.

HTML5 JavaScript Tailwind CSS (CDN) Groq API

NLP & Visualization

LLM Token Explorer (Tokeniser v2.5)

Client-side HTML/CSS/JS suite • Tailwind CSS via CDN, no build step

A client-side suite for inspecting subword tokenization, training Byte-Pair Encoding vocabularies step by step, and exploring 3D token embeddings.

  • Live tokenization across Flow, Chips, Table, and Raw IDs views with a UTF-8 byte/hex inspector and side-by-side GPT-4o, Llama 3, Claude 3.5, and Gemma 2 comparisons.
  • Interactive BPE Vocabulary Builder, 3D Canvas embedding visualizer with custom token placement, Logits Sampling Simulator, and Inference Cost Estimator.

What I learned: Projecting 3D token coordinates onto a 2D HTML5 Canvas with rotation matrices, depth-sorted hit testing, and live BPE pair-frequency merging taught me how subword vocabularies and embedding geometry behave under the hood.

HTML5 JavaScript Tailwind CSS (CDN) 3D Canvas
